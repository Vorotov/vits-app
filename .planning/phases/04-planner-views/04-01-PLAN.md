<objective>
Prove the whole Phase-4 architecture on one thin, production-quality path: real regimens in the real database → pure window and run derivation → one cached provider → a gantt that a user can actually reach from the Calendar tab and read — with a test proving the trip writes nothing. Then widen the pure layer to every projection the rest of the phase renders from.

Purpose: the planner's defining risk is not layout, it is deriving a year of calendar state the expensive way. Wiring the read-only projection end-to-end first — and pinning the zero-write invariant with a row-count regression on the very first commit — means every later plan is pure rendering over an already-proven model.
Output: window helpers in `cycle_math.dart`, the clockless `planner_view_model.dart`, `planner_providers.dart`, `planner_gantt.dart`, a reachable `planner_screen.dart`, the eight Phase-4 tokens, and four new test files.
</objective>
