|----------|-------------|
| Derived "missed" → persistence | The locked semantics forbid any write on this path; a leak here silently rewrites the user's record of what they took |
| Browsed day → materialization | Browsing a never-opened past day writes new rows; those writes must be pending-only and cycle-truthful |
| Error surface → user | Exception text from the storage layer must never reach the screen |
