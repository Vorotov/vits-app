## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Row gesture → IntakeRepository | The only path in the app that writes a `DoseStatus`; user taps cross into persistence here |
| Provider build → materialization | `ensureLogsForDay` writes rows on every rebuild; a non-idempotent or mis-keyed call would corrupt or duplicate a user's day |
| System clock → app state | The device clock (and its timezone) determines which day is "today" and therefore which rows are written and read |
