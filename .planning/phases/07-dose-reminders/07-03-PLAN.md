<objective>
Make the notification tap able to reach the Сьогодні tab, and make a cold start from a tap correct on the very first frame.

Two things stand in the way. The selected destination is local widget state, so nothing outside the shell can change it. And the plugin's initialization callback is documented as unable to handle a launch-from-tap at all, so the cold-start answer has to be read separately and has to be available before the app is run — otherwise the user watches Стек paint and then jump, which is exactly the defect the decision to read it early exists to prevent.

The tap does two things and only two: it selects Сьогодні and it returns the browsed day to today. The second is not an extra; without it the reminder lands on whatever day the user last browsed.

Purpose: NOTIF-01's second half — tapping opens Сьогодні.
Output: an app-lifetime tab notifier, a guarded launch-payload read, one tap handler shared by the warm and cold paths, and the four Phase-6 shell test files still green with their accessibility assertions unedited.
</objective>
