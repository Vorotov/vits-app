    1. Create `build.yaml` at repo root configuring the drift_dev builder with option `store_date_time_values_as_text: true` — SQLite then stores DateTimes as ISO-8601 strings with UTC suffix, so DateTime.utc values read back as UTC. Without this, drift's default unix-timestamp storage reads back local-time DateTimes, silently breaking the UTC-midnight calendar identity D-13/D-18 require (equality with DateTime.utc fails on the isUtc flag). Document this rationale in a build.yaml comment.
    2. Create `lib/core/db/database.dart` per RESEARCH Pattern 2 verbatim syntax (per D-17/D-18):
       - `mixin SyncColumns on Table` with `TextColumn get id => text()();`, `DateTimeColumn get createdAt => dateTime()();`, `DateTimeColumn get updatedAt => dateTime()();`, `DateTimeColumn get deletedAt => dateTime().nullable()();` and `@override Set<Column> get primaryKey => {id};`. No client-side defaults — every writer supplies explicit UTC instants (keeps timestamps deterministic and test-controllable; repositories in 01-07 own this).
       - `class Supplements extends Table with SyncColumns`: name text, doseText text, colorValue integer, note text.
       - `class Regimens extends Table with SyncColumns`: supplementId text references Supplements #id; kind intEnum<RegimenKind>(); startDate dateTime; endDate dateTime nullable; onDays integer default 0; offDays integer default 0; paused boolean default false.
       - `class RegimenSlots extends Table with SyncColumns`: regimenId text references Regimens #id; minutesFromMidnight integer; doseLabel text.
       - `class IntakeLogs extends Table with SyncColumns`: regimenId text references Regimens #id; slotId text references RegimenSlots #id; date dateTime (doc comment: UTC-midnight calendar identity); status intEnum<DoseStatus>() (stored as the enum index, satisfying D-18); `@override List<Set<Column>> get uniqueKeys => [{slotId, date}];`.
       - `@DriftDatabase(tables: [...])` `class VitomyDb extends _$VitomyDb` with `VitomyDb.forTesting(super.executor);`, `VitomyDb.open() : super(driftDatabase(name: 'vitomy'));` and `schemaVersion => 1` (per D-19). On `.open()` write the D-21 doc comment: driftDatabase resolves the file into the platform app-documents directory — iOS documents dir (backed up by default) / Android internal app data (Auto Backup-eligible by default) — and the app must never opt the file or app out of OS backups (DATA-02).
