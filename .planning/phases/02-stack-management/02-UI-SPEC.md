# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** Phase 2 delivers three UI surfaces — the Stack screen ("Мій стек", mockup screen 01), the add-supplement bottom sheet (search + manual tabs), and the regimen editor screen ("Розклад прийому", mockup screen 05). Authoritative visual source: `claude_design_mockup/VitoMy v0.1.dc.html` (read in full; line citations below refer to it). The mockup is authoritative for *visuals*, not *scope* — see "Mockup Deviations Locked for v1" for content that must NOT ship (per 02-RESEARCH.md PF-5).
>
> **Consumption rule:** the design system is ESTABLISHED (Phase 1). All styling goes through `BqColors` / `BqSeriesColors` / `BqRadii` / `BqSpace` / `bqTheme()` / `BqText.mono()` in `lib/core/theme/` — token names are referenced BY NAME throughout this contract. Genuinely new mockup-sourced values are enumerated ONLY in the "Token Additions" table; nothing else may introduce a literal.

## Screen Contracts

### S1 — Stack screen (mockup screen 01, lines 78-121)

- Header: `heading` "Мій стек" + `stackSummary` body-13 `textMuted` 4px below; 18px gap to CTA row.
- Primary CTA: full-width accent button, radius `BqRadii.button`, padding 13, Instrument 14/600 white; pressed `accentPressed`.
- Eyebrow: mono label "ДОБАВКИ" (`BqText.mono(10.5)`, `textMuted`), 10px above the list.
- Card anatomy (each `StackEntry`): `surface` bg, 1px `cardBorder`, radius `BqRadii.card`, padding 14, row = [4px color-tag bar (supplement color, opacity .85, radius 3)] + 12px gap + column [name 15/600 → doseText 12.5 `textMuted` (3px below) → chips row (10px below, `Wrap`, 6px gaps)].
- Chips row: status chip (mono 10.5/500, colors per status table) + schedule-summary chip (Instrument 11.5, `textSecondary` on `chip`, radius `BqRadii.chip`). A `fresh` entry (no regimen yet — E-7) renders NO schedule chip.
- Schedule-summary text: cyclic → `cycleSummaryCyclic`-style short form + `slotsPerDay`; course → locale date range via `DateFormat.yMd` (uk "14.08.2026 – 30.09.2026"); paused regimens keep their summary (status chip carries the pause signal).
- Card tap → RegimenEditorScreen(supplementId). Whole card is the tap target (≥48px tall by construction).

### S2 — Add-supplement sheet (lines 125-165)

- `showModalBottomSheet(isScrollControlled: true)`, barrier `scrim`, sheet `paper`, top radius `BqRadii.sheet`, drag handle 38×4 `dragHandle` centered, padding 10/20/26 + keyboard inset (`MediaQuery.viewInsetsOf(context).bottom`, directional padding — PF-6).
- Header row: title 18/600 + trailing "Закрити" text button (13/400 `accent`).
- `BqSegmented` two tabs: "Пошук у базі" / "Вручну" (manual tab REPLACES the mockup camera tab — locked v1 scope).
- Search tab: input (surface fill, radius `BqRadii.input`, 1px `inputBorder`, padding 13/14, hint `searchCatalogHint` "Назва або діюча речовина") → result list (10px gaps): surface rows, radius `BqRadii.button`, 1px `cardBorder`, padding 13/14, name 14/600 + doseText 12/400 `textMuted` 2px below + trailing "+" 20/500 `accent`. Empty query shows the full 15-entry catalog; matching is trim+lowercase `contains` across active locale AND en (P-2).
- Manual tab: name field (required, non-empty after trim — Save disabled otherwise) + dose field (optional), same input styling; `textCapitalization: sentences` (PF-9); primary CTA is `addManualSupplement` ("Додати добавку" / "Add supplement" — Copywriting Contract row), styled as the accent primary button, disabled until name is non-empty after trim.
- On pick/save: create supplement (round-robin series color), close sheet, push RegimenEditorScreen.
