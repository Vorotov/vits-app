<objective>
Prove the whole L10N-03 loop end-to-end on one path: a user opens Settings, taps a language row, the entire app re-reads in that language within one frame, and the choice survives a restart — with the language set derived from the ARB files on disk rather than enumerated in code.

Purpose: this is the phase's hardest criterion (criterion 3 "instantly … and persists", criterion 4 "one new ARB file, no code changes") and the only genuinely new screen. Proving it first means the criterion-4 gates in 05-03 and the render matrix in 05-04 are written against a real, working loop rather than against an intention.

Output: the Settings screen and its language picker, a derived-not-enumerated LocaleController seeded synchronously from an injected SharedPreferences, the three new ARB keys, the declared English fallback, and the widget tests that prove the loop.
</objective>
