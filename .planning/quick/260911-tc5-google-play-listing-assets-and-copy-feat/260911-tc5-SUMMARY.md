## Deviations from Plan

### Verify-harness correction (no code impact)

**1. [Rule 3 - Blocking] Task 1's verify block shadowed the system python3.**
- **Found during:** Task 1 verify
- **Issue:** The block does `export PATH="/opt/homebrew/bin:$PATH"`, which
  makes `python3` resolve to Homebrew's interpreter, which has no Pillow.
  Pillow 11.3 lives only in `/usr/bin/python3` — the interpreter the plan's
  non-negotiable 7 names. The block failed with `ModuleNotFoundError: No
  module named 'PIL'` before reaching any assertion about the work.
- **Fix:** Re-ran the identical block with Homebrew appended
  (`export PATH="$PATH:/opt/homebrew/bin"`), so `flutter` still resolves and
  `python3` stays the system one. `TASK1_OK`. The same PATH order was used for
  Task 3's verify (`TASK3_OK`), which is otherwise unaffected.
- **Files modified:** none

Otherwise the plan executed exactly as written. One small style choice worth
recording: the test file's first doc-comment line was extended on one line
as the plan asked; it was already over 80 columns before this task and
`flutter analyze` does not flag it.
