## Facts

  320-3840 px, the long side at most TWICE the short side; 4+ at 1080 px or
  more for promotion eligibility (support.google.com/googleplay/android-developer/answer/9866151).
  The iOS captures (1284x2778 = 2.16:1, 1320x2868 = 2.17:1) fail the 2:1 rule,
  and so does every modern phone AVD profile (Pixel 7 = 1080x2400). So the
  Play set was captured on a purpose-made AVD `play_shots`: Pixel 2 profile,
  1080x1920 @ 420 dpi (exactly 9:16). The five files are ALREADY in
  `store/screenshots/android-phone/01-stack.png … 05-schedule.png`, 1080x1920,
  flattened to RGB, captured by `260911-tc5-make_screenshots_android.sh` (this
  directory) from the same `integration_test/store_screenshots_test.dart`
  the iOS set uses, with the SystemUI demo-mode status bar (9:41, full
  battery, wifi only). Do NOT recapture: it needs the booted emulator.
- Feature graphic: 1024x500, JPEG or 24-bit PNG (no alpha); keep the focal
  point central, no store badges, no ranking/price claims, tagline small.
  `260911-tc5-make_feature_graphic.py` (this directory) renders it from
  `tool/make_icons.py`'s `draw_mark('3b', …)` plus the design tokens
  (paper #F7F6F3, accent #4A4E7C, textSecondary #5C5C66) with the bundled
  Instrument Sans variable font: the V mark left, the wordmark "VitoMy", a

  take." Preview: `260911-tc5-feature-graphic-preview.png`. The script currently

  derive ROOT from `__file__` (parent.parent) like make_icons.py, and default
  its output to `store/feature/feature-graphic-1024x500.png`.
- The AVD recipe (machine-local, so the script header must carry it):
  `avdmanager` needs Java (none on PATH; Android Studio's JBR at
  `/Applications/Android Studio.app/Contents/jbr/Contents/Home` works as
  JAVA_HOME if present). The working shortcut: copy an existing AVD's
  `config.ini` + `.ini` under `~/.android/avd/` to `play_shots`, set
  `AvdId`/`avd.ini.displayname`=play_shots, `hw.device.name=pixel_2`,
  `hw.lcd.width=1080`, `hw.lcd.height=1920`, `hw.lcd.density=420`,
  `skin.name=1080x1920`, `skin.path=_no_skin`; boot with
  `emulator -avd play_shots -wipe-data -no-snapshot -no-boot-anim -no-audio -gpu swiftshader_indirect`.
