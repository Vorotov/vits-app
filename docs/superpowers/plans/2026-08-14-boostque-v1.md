# Boostque v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the v1 core loop of Boostque — a supplement stack with scheduled doses (cycles), a calendar with Today/Cycles/Year views, local-only storage, full i18n (uk + en, system-detected with manual override).

**Architecture:** Flutter single codebase. Feature-first layout; UI depends on repository interfaces (never on Drift directly); cycle math is pure Dart in `core/domain`. Dose occurrences are materialized as `IntakeLog` rows so future widgets/notifications can read them. All rows use UUID PKs + createdAt/updatedAt + soft delete for future backend sync.

**Tech Stack:** Flutter 3.47 / Dart 3.13, flutter_riverpod, drift (SQLite), gen-l10n (ARB), google_fonts, shared_preferences, uuid.

**Spec:** `docs/superpowers/specs/2026-08-14-boostque-v1-design.md`
**Design reference:** `claude_design_mockup/Boostque v0.1.dc.html` (authoritative; screens 01–05)

## Global Constraints

- Project name `boostque`, org `com.boostque`, bundle id placeholder `com.boostque.dev` (final name/id is an open item — decide before store release).
- The Flutter project lives at the **repo root** (`/Users/dima/supplements`).
- Zero hardcoded user-visible strings — every string comes from `AppLocalizations` (ARB). Ukrainian plural forms use ICU plurals. Copy vocabulary (from mockup): цикл, перерва, слот, прийнято, одночасно; never promise health effects.
- All dates are date-only values normalized as `DateTime.utc(y, m, d)` — never local midnight (DST safety).
- All DB tables: `TEXT` UUID primary keys, `createdAt`, `updatedAt`, nullable `deletedAt` (soft delete). Queries always filter `deletedAt IS NULL`.
- UI reads data ONLY through `SupplementRepository` / `RegimenRepository` / `IntakeRepository` interfaces.
- Palette/typography from mockup (see Task 2 tokens) — accent `#4A4E7C`, paper `#F7F6F3`, ink `#17171B`, calm/warn/risk `#3F7A6A`/`#B07A22`/`#A8443C`, fonts Instrument Sans + JetBrains Mono (numbers).
- No fixed-width text containers; use `EdgeInsetsDirectional` for horizontal padding (RTL-ready).
- Every task ends with `flutter analyze` clean and `flutter test` green before commit.

```dart
// lib/core/l10n/locale_controller.dart
import 'dart:ui';
import 'package:flutter/widgets.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:shared_preferences/shared_preferences.dart';
import 'gen/app_localizations.dart';

const _kLocaleKey = 'app_locale';

final localeControllerProvider =
    NotifierProvider<LocaleController, Locale?>(LocaleController.new);

class LocaleController extends Notifier<Locale?> {
  @override
  Locale? build() {
    _load();
    return null; // null = follow system
  }

  Future<void> _load() async {
    final prefs = await SharedPreferences.getInstance();
    final code = prefs.getString(_kLocaleKey);
    if (code != null) state = Locale(code);
  }

  Future<void> setLocale(Locale? locale) async {
    state = locale;
    final prefs = await SharedPreferences.getInstance();
    if (locale == null) {
      await prefs.remove(_kLocaleKey);
    } else {
      await prefs.setString(_kLocaleKey, locale.languageCode);
    }
  }
}

extension L10nX on BuildContext {
  AppLocalizations get l10n => AppLocalizations.of(this);
}
```

```dart
// lib/core/domain/cycle_math.dart
import 'models.dart';

DateTime dateOnly(DateTime d) => DateTime.utc(d.year, d.month, d.day);

bool isActiveOn(Regimen r, DateTime day) {
  if (r.paused) return false;
  final d = dateOnly(day);
  final start = dateOnly(r.startDate);
  if (d.isBefore(start)) return false;
  switch (r.kind) {
    case RegimenKind.course:
      final end = r.endDate;
      return end != null && !d.isAfter(dateOnly(end));
    case RegimenKind.cyclic:
      final period = r.onDays + r.offDays;
      if (r.onDays <= 0) return false;
      if (period == r.onDays) return true; // no break
      return d.difference(start).inDays % period < r.onDays;
  }
}

bool isPlannedOn(Regimen r, DateTime day, DateTime today) =>
    dateOnly(r.startDate).isAfter(dateOnly(today)) && isActiveOnIgnoringStartFuture(r, day);

// Same pattern test but allows evaluating dates at/after a future start.
bool isActiveOnIgnoringStartFuture(Regimen r, DateTime day) {
  final unpaused = Regimen(id: r.id, supplementId: r.supplementId, kind: r.kind,
      startDate: r.startDate, endDate: r.endDate, onDays: r.onDays,
      offDays: r.offDays, paused: false, slots: r.slots);
  return isActiveOn(unpaused, day);
}
```

```dart
import 'package:drift/drift.dart';
import '../domain/cycle_math.dart';
import '../domain/models.dart';
import '../domain/repositories.dart';
import 'database.dart';

class DriftSupplementRepository implements SupplementRepository {
  DriftSupplementRepository(this.db);
  final BoostqueDb db;

  @override
  Stream<List<Supplement>> watchAll() =>
      (db.select(db.supplements)..where((t) => t.deletedAt.isNull())
        ..orderBy([(t) => OrderingTerm.asc(t.createdAt)]))
          .watch().map((rows) => rows.map(_toSupplement).toList());

  @override
  Future<void> upsert(Supplement s) => db.into(db.supplements).insertOnConflictUpdate(
      SupplementsCompanion.insert(id: s.id, name: s.name, doseText: s.doseText,
          colorValue: s.colorValue, note: s.note)
        .copyWith(updatedAt: Value(DateTime.now().toUtc())));

  @override
  Future<void> softDelete(String id) =>
      (db.update(db.supplements)..where((t) => t.id.equals(id))).write(
          SupplementsCompanion(deletedAt: Value(DateTime.now().toUtc()),
              updatedAt: Value(DateTime.now().toUtc())));
}

class DriftIntakeRepository implements IntakeRepository {
  DriftIntakeRepository(this.db);
  final BoostqueDb db;

  @override
  Future<void> ensureLogsForDay(DateTime day) async {
    final d = dateOnly(day);
    final regimens = await DriftRegimenRepository(db).watchAll().first;
    await db.batch((b) {
      for (final r in regimens.where((r) => isActiveOn(r, d))) {
        for (final slot in r.slots) {
          b.insert(db.intakeLogs,
              IntakeLogsCompanion.insert(
                  id: '${slot.id}_${d.millisecondsSinceEpoch}',
                  regimenId: r.id, slotId: slot.id, date: d,
                  status: DoseStatus.pending.index),
              mode: InsertMode.insertOrIgnore);
        }
      }
    });
  }

  @override
  Future<void> setStatus(String logId, DoseStatus status) =>
      (db.update(db.intakeLogs)..where((t) => t.id.equals(logId))).write(
          IntakeLogsCompanion(status: Value(status.index),
              updatedAt: Value(DateTime.now().toUtc())));

  @override
  Stream<List<DayDose>> watchDay(DateTime day) {
    final d = dateOnly(day);
    final q = db.select(db.intakeLogs).join([
      innerJoin(db.regimenSlots, db.regimenSlots.id.equalsExp(db.intakeLogs.slotId)),
      innerJoin(db.regimens, db.regimens.id.equalsExp(db.intakeLogs.regimenId)),
      innerJoin(db.supplements, db.supplements.id.equalsExp(db.regimens.supplementId)),
    ])
      ..where(db.intakeLogs.date.equals(d) &
          db.regimens.deletedAt.isNull() & db.supplements.deletedAt.isNull())
      ..orderBy([OrderingTerm.asc(db.regimenSlots.minutesFromMidnight)]);
    return q.watch().map((rows) => rows.map((row) { /* build DayDose */ }).toList());
  }
}
```
